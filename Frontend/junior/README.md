# UniAssist: Academic Excellence

UNIASSIST — FRONTEND DEVELOPMENT & DESIGN PROMPT

1. PROJECT OVERVIEW

Build the frontend for UniAssist, a premium student academic-support platform developed by Balerioncodes.

Product tagline

Academic support, without the stress.

UniAssist connects students with the right support for academic and technical needs, including:

 Academic tutoring

 Study support

 Programming and debugging assistance

 Software/application installation and setup

 Technical support

 Research guidance

 Project guidance

 Final-year project support

 Documentation and proofreading

 Other legitimate academic and technology support services

The platform should feel like a serious technology product, not a generic school website.

The experience should communicate:

Trust • Intelligence • Support • Technology • Academic Excellence

2. IMPORTANT — BRAND IDENTITY

The visual identity MUST be based on the Balerioncodes brand.

Use the uploaded Balerioncodes logo as the primary visual reference.

The Balerioncodes identity is built around:

Near-black

Deep teal

Emerald teal

Mint / aqua green

Ivory / off-white

Soft silver / gray

The strongest visual combination should be:

Near-black + Deep Teal + Emerald + Mint + Ivory

32. FINAL DESIGN STANDARD

The final result should make someone think:

"This looks like a serious technology company built this."

Not:

"This looks like a university assignment."

Use the Balerioncodes identity as the DNA, while allowing UniAssist to develop its own personality.

The Balerioncodes visual language should be recognizable through:

dark premium surfaces + deep teal + emerald + mint glow + ivory typography + clean modern UI.

However, don't force every screen to be dark.

Use:

Dark Balerioncodes-inspired sections for hero areas, navigation, featured content and important dashboards.

Light neutral surfaces for forms, tables, reading areas and information-heavy pages.

Emerald/mint accents for actions and important highlights.

Ivory as an elegant supporting brand color.

Teal/emerald gradients only where they genuinely improve the design.
